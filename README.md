## 관심 분야

### Gameplay Programming
게임플레이 로직과 시스템을 설계하고 구현하는 것에 관심이 있습니다.

### Game Systems
플레이어가 직접 체감하는 게임 메커니즘과 시스템 구조를 공부하고 있습니다.
